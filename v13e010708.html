EJ-EG-B-16

Diseñado para medir la temperatura de los huevos en sus empaques durante su transporte y almacenaje o durante el proceso de incubación. El huevo registrador se puede utilizar en lugares de poco espacio.

  • Rango de -20ºC a +60 ºC
  • Precisión del sensor de ±0.3 ºC
  • Memoria de 16,000 registros
  • Dimensiones:
    • Altura: 59mm.
    • Diámetro: 45mm.
  • Recuperación de datos mediante interfaz MN-INT-E a la PC, o impresión directa mediante graficador EJ-CR
  • Incluye software gratuito para graficar datos recolectados

EI-HS-D-32-L

El registrador mide y guarda temperatura y humedad, ofreciendo una gran flexibilidad y funcionamiento ya que cuenta con sensores incorporados. Puede ser programado para iniciar automáticamente mediante software o usando un imán.

  • Rango de medición:
    Temperatura: -40 °C / +70°C
    Humedad: 0-100% RH
  • 16,000 registros por sensor
  • LEDs de actividad y alarma
  • Pantalla LCD
  • Tamaño: 76mm. x 86mm. x 28mm.
  • Requiere interfaz EA-INT-USB para descargar datos
  • Incluye software gratuito para graficar datos recolectados

COOL DOWN (EC-OE-C-L)

Este registrador permite controlar el proceso de enfriamiento de los alimentos procesados, registrando cada 2 horas la temperatura de acuerdo a las normas de la FDA, indicando si se cumplen o no dichas normas.

  • Rango de medición: -20°C a +100°C
  • Vida de la batería: 14 meses
  • Muestreo: en intervalos de 2 a 6 horas
  • Tamaño: 80mm. X 57mm. X 22mm.
  • Programación vía PC a través de una interfaz RS232 con conector DB9 o a través del convertidor LB-USB232
  • Incluye software gratuito para graficar datos recolectados
